# 🌅 Aurora Engine

> Analisi quantitativa per **Super Win for Life** — Vinci per la Vita

Sistema ingegnerizzato per l'analisi statistica del gioco Super Win for Life.
Non predice i numeri (matematicamente impossibile), ma ottimizza:

- 🎯 **Anti-crowd**: gioca numeri impopolari → se vinci, prendi di più
- 📊 **Matematica esatta**: probabilità ipergeometriche, EV, Kelly criterion
- 🧠 **Fingerprint statistici**: 12 metriche derivate dalle estrazioni reali
- 🎛️ **Budget dinamico**: disciplina EV-based
- 📈 **Tracking**: sa cosa hai giocato e come sta andando
